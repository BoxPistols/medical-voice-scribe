## アプリについて

音声で交わした問診をSOAP形式のカルテに変換するデモです。医療カルテのほかに、症状チェッカー、ヘルスコーチ、気分ジャーナル、呼吸・瞑想、体を動かす、音声メモ、メンタリング、時計の9つのモードがあります。

デモ用途のもので、臨床では使えません。

## Storybookの歩き方

初めて開いた方向けに、最低限の操作だけ書いておきます。

| したいこと | 操作 |
| --- | --- |
| 部品を探す | 左のサイドバー。上の検索窓は `⌘K` でも開く |
| 明色と暗色を見比べる | 上部ツールバーの「テーマ」を切り替える |
| 値を変えて試す | 下部のControlsタブでpropsを編集する |
| 使い方とpropsの一覧を読む | 各部品のDocsを開く |
| コードを見る | 表示の下にあるShow code |
| 画面幅を変える | ツールバーのビューポート切り替え |

## どこから見るとよいか

| 場所 | 中身 |
| --- | --- |
| デザイン / デザイントークン | 色の一覧です。実際に描画されている値とコントラスト比を出しています。値を書き写していないので実装とずれません |
| デザイン / コンポーネント一覧 | 部品を1枚に並べたページです。系として揃っているかを見るのに使います |
| Components | 個々の部品です。状態ごとのストーリーが入っています |

## 色の決まり

色は意味を持つ名前だけで書きます。`bg-red-50` のような数字付きのTailwindクラスはコンポーネントに書きません。

役割は `brand` `danger` `warning` `info` `success` の5つで、それぞれが6段の階調を持ちます。詳しくはリポジトリの `docs/design-tokens.md` にあります。

決まりを外れた記述はテストとエディタのフックが止めるので、書いた直後に気づけます。
